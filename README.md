# PixForge IMS — Desktop releases

ตัวติดตั้ง (installer) + feed อัปเดตอัตโนมัติของ **PixForge IMS** (desktop app).

- Windows: `PixForge-IMS-Setup-<ver>.exe`
- macOS: `PixForge-IMS-<ver>-arm64.dmg`

ซอร์สโค้ดอยู่ใน repo ส่วนตัวแยกต่างหาก — ที่นี่เก็บเฉพาะไฟล์ติดตั้งเพื่อให้
แอปเช็กอัปเดตเองได้ (electron-updater อ่าน `latest.yml` / `latest-mac.yml`).
